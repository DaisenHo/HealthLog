# T01：Web 账户语言切换

对应 [T01 / Issue #2](https://github.com/DaisenHo/HealthLog/issues/2)。本任务接通 Web 简体中文 / English 选择与账户偏好，保留原有九种语言。M1 的完整中文发布仍由后续任务与 T10 验收决定。

## 使用流程

- 未登录时，从系统语言或本机缓存确定初始语言；登录、注册页可手动切换。
- 注册时将当前语言保存到新账户；登录已有账户时恢复该账户语言，旧浏览器缓存不会覆盖账户偏好。
- 引导页和账户设置均可切换语言；成功保存后刷新服务端文案，同时保留当前页面状态。
- 账户保存成功后再更新界面和本机缓存。离线、服务失败或已登录页面的会话过期均保留原语言并显示提示。
- 尚未选择语言的旧账户沿用服务端配置的默认语言；配置无效或缺失时使用 English。页面、账户接口与后台任务共用同一回退规则。
- 切换语言只调整界面语言及日期、数字等呈现方式，不修改单位偏好、账户时区或原始业务数据。

## 供 iOS 复用的接口

| 方法与路径                | 响应 / 请求                                    | 说明                                                                |
| ------------------------- | ---------------------------------------------- | ------------------------------------------------------------------- |
| `GET /api/auth/me/locale` | `{"data":{"locale":"zh-CN"},"error":null}`     | 读取调用者的账户语言；支持会话或 Bearer 认证。未认证返回 401。      |
| `PUT /api/auth/me/locale` | 请求 `{"locale":"zh-CN"}`，成功返回相同 locale | 显式保存调用者的语言，同时更新浏览器 cookie；不支持的语言返回 422。 |
| `GET /api/auth/me`        | 既有账户响应新增 `data.locale`                 | 与独立语言读取接口使用相同解析规则。                                |

语言标识使用 `zh-CN` 和 `en`，原有语言标识继续有效。系统的 `zh-Hans`、大陆简体等常见标签会集中映射到 `zh-CN`；不把繁体标签直接当作简体。

这些接口属于操作者本人。查看他人共享档案时，语言偏好仍属于操作者，不会修改档案所有者的语言。完整字段与拒绝条件以 `docs/api/openapi.yaml` 为准。

## 翻译覆盖与后续边界

精确清单见 `t01-localization-coverage.json`，当前翻译 621 个键，包括登录、注册、引导、账户设置、通用导航，以及这些路径的常见校验、错误和空状态。

其余功能文案在本集成阶段保留英文，由 T03、T04、T05、T06 继续完成。已验证量表在没有获准的中文版本时保留英文原文；AI 文案及其安全契约保留经过审查的英文，待 T06 处理。不得将本任务作为 M1 已完成或完整中文可发布的依据。

## 验证范围

- 浏览器用例覆盖公开页真实切换、系统简体标签、刷新、旧浏览器、重新登录、引导切换、登录失败、保存失败、会话过期与离线。
- 使用隔离 PostgreSQL 验证账户保存、注册语言、默认语言一致性、Bearer 读取、无效语言拒绝及匿名访问拒绝。
- 沿用既有全量单元测试、类型检查、静态检查、格式检查、OpenAPI 同步检查及生产构建。
- iOS 界面和跨端交互由后续 iOS 票据验收；本任务不宣称已经验证真机同步。
