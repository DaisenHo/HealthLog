# T03：Web 健康记录、趋势与图表中文闭环

对应 [Web #3](https://github.com/DaisenHo/HealthLog/issues/3)，基于 T01 账户语言功能继续。此任务不代表 M1 全部完成或已经发布。

## 覆盖范围

沿用既有 catalog、翻译函数和界面，覆盖健康概览、测量录入与历史、自定义指标、图表及参考范围、趋势分析、时间线与活动日历、来源说明及共享空/错误状态。

精确范围见 [词条覆盖清单](t03-localization-coverage.json)：范围内共 2,750 个键，其中 2,701 个有中文文案，49 个保留合法的品牌、医学缩写、单位或纯格式模板。没有删除键、改动其他语言或自由翻译受验证问卷。

无模型计算的“通常范围”摘要、目标范围组件及共享情绪上下文标签一并覆盖。Coach 的对话及模型文案仍由 T06 负责；独立用药/目标流程、其他健康模块、报告/分享/管理等仍由 T04–T06 完成。共享分析界面的译文不代表对应模块的全部表单已经翻译。

## 日期与数字

- 中文 AUTO 日期显示和手动输入统一按年/月/日处理；明确选择 DMY、MDY、YMD 时继续采用所选顺序。
- 中文选择非 AUTO 日期顺序时，只调整数字字段排列，星期和上下午仍使用中文；H12/H24 和账户时区照常生效。
- 沿用原有 Intl、date-fns 和日历组件。计量单位、原始值、聚合、目标阈值、评分与数据来源策略不变。
- 医学说明保留上游的数值、出处及限制，区分个人通常范围、指南范围与设备估算，不新增诊断或建议逻辑。

## 验证边界

- 扩展既有趋势卡片和日期字段的公开渲染测试，检查中文可见内容及数值、单位和 ISO 日期保留。
- 扩展共享格式器测试，检查中文搭配显式日期顺序、时区及 H12/H24；保留其他语言断言。
- 浏览器旅程使用隔离 PostgreSQL 中的独立虚构账户，正常操作账户语言及测量表单，通过真实 API 保存和读取，在中英文及 1,280/390 像素视口下查看记录、体重图表和时间线，并刷新验证语言。
- 此旅程在一个浏览器项目内依次检查两个视口，避免并行项目修改同一账户语言；不会通过注入语言 cookie 代替操作，也不模拟测量或图表接口。
- 测试夹具只清理专属虚构账户的测量，避免旧记录影响图表均值。不能将测试配置指向真实健康数据库。
