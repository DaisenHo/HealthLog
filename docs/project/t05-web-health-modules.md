# T05：Web 其他健康模块中文闭环

对应 [Web #5](https://github.com/DaisenHo/HealthLog/issues/5)，基于 T04 提交 `f8fb64af9e8851f4899013c3c8e5dbfeee4fe2f4`。此任务不代表 M1 完整发布。

## 范围

覆盖疾病日志、个人病史与生活状况、家族史、过敏与急救信息、检验目录/录入/历史/趋势/报告识别、疫苗、情绪与标签、周期与关联分析、心理自评外围界面、营养、就诊/处置/医生通讯录、身体部位、症状及医疗文档库。纳入这些模块共用的关联选择器、排列设置、环境指标和 API 错误提示。

精确范围见 [词条覆盖清单](t05-localization-coverage.json)：2,325 个键，其中 2,302 个为中文（含沿用前序任务的译文），23 个保留规范缩写、官方服务/产品名称、单位、快捷键或纯格式模板。报告、完整分享/导出、管理、Coach 对话与模型文案及其余配置辅助界面仍由 T06 处理。

沿用既有 catalog、组件和公开 API。药品、用户填写的疾病/疫苗/指标名称、自由文本及文件名不自动翻译；数值、单位、来源、时区、评分、界值、预测、权限及 AI 调用范围保持原有行为。表单失败时复用既有机器码翻译和本地化兜底，保留原有错误状态及权限拒绝。

## 受验证问卷

- 不增加中文受验证语言白名单，不修改题目、选项、回顾期题干、PHQ-9 后续题、评分或例外清单。
- 现有规则要求中文显示原版英文题目。79 个受限键继续不进入中文 catalog，由既有 `instrumentText` 读取英文原文，并显示中文说明。
- PHQ-9、GAD-7、WHO-5、SCI 的外围操作、历史、结果说明及支持信息采用中文；研究出处、许可与官方服务名称保留原意。
- AUDIT-C 的标准份量帮助文案可翻译，现已补齐中文；原版三题、选项、来源与分界值保持不变。筛查提示继续注明来源国家，不转换为中国地区规则，也不新增医疗判断。

中文检验名称的 FHIR 兼容修复仅保留名称中的汉字，使目录别名继续解析到既有 LOINC 编码。没有新增编码或单位映射；未知指标仍保持纯文本，单位沿用原有匹配规则。

## 验证边界

- 扩展既有公开渲染测试，检查中文检验换算说明保留来源数值/单位，以及四项心理量表的中文外壳搭配英文原文。
- 扩展 AUDIT-C 公开返回值测试，验证英文题目与中文帮助并存；既有题目字节摘要和语言限制测试保持不变。
- 使用专属虚构账户及隔离 PostgreSQL；中英流程在一个浏览器项目中依次运行，避免语言设置与 T03 的独立账户互相干扰。
- 十条真实界面/API 旅程覆盖疾病、检验、疫苗、家族史、就诊、情绪、周期、WHO-5、手动饮水及文档上传/打开；英文桌面、中文窄屏，保存后通过公开 API 回读，保留账户单位和时区。
- 检验使用无效数字触发原有应用校验；疫苗提交通过真实服务端拒绝一次无效请求后再保存。周期日记录按既有新建/编辑行为验证：POST 为 201/200，PATCH 为 200，删除为 204。
- 文档仅验证普通加密保存及读取，不配置或调用外部 AI、文档档案服务，也不验收独立 worker 的缩略图处理。独立数据库在本次验收后清理；正式远程部署及 HealthKit/小米真机不在此任务内。
